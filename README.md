# 电梯维修操作证（T证）刷题

移动端优先的电梯修理作业人员（T证）刷题单页应用。单文件、零依赖，双击 `index.html` 即可做题。

**🔗 在线刷题（手机浏览器直接打开）：<https://taiyang-alt.github.io/elevator-quiz/>**

> 依据《特种设备作业人员考核规则》TSG Z6001-2019 附件 H 的电梯作业人员考试大纲整理，共 **503 题**，每题附答案与解析。

## 功能

| 模块 | 说明 |
|---|---|
| 顺序练习 | 按题库顺序逐题做，答错立即在下方展开正确答案与解析 |
| 章节练习 | 8 个章节任选，薄弱章节集中突破 |
| 随机练习 | 打乱顺序，避免形成位置记忆 |
| 背题模式 | 不做题，直接亮出正确项 + 解析，适合考前快速过一遍 |
| 模拟考试 | 按真实题型比例组卷，倒计时、交卷评分、成绩与错题解析 |
| 错题本 | 答错的题自动收录，**只能手动移出**，不会被自动清空 |
| 未作答清单 | 考试中漏做的题单独归档，不与错题混在一起 |
| 收藏 / 统计 | 收藏夹、累计答对率、今日练习量、题库掌握进度环 |
| 断点续做 | 练习进度与未完成的考试均可恢复，倒计时继承原结束时间 |

**判定规则**：单选、判断点击选项立即判定；多选需点底部「确定」，多选／少选／错选均不得分。

## 部署到 GitHub Pages

仓库内置工作流 `.github/workflows/pages.yml`，推送到 `main` 分支后自动发布：

**自动方式（推荐）**：推送后无需任何操作。工作流里 `actions/configure-pages` 带 `enablement: true`，会在 Pages 尚未开启时自动开启。

**手动方式（自动开启失败时）**：打开仓库 **Settings → Pages**，把 **Source** 设为 **GitHub Actions**，再重新运行一次工作流。

访问地址：`https://<你的用户名>.github.io/<仓库名>/`

想改用分支部署也可以：**Settings → Pages → Source → Deploy from a branch → main / (root)**，此时建议删掉 `.github/workflows/pages.yml` 以免两者冲突。

## 自行加题

题库内联在 `index.html` 的第一个 `<script>` 块中，格式如下：

```js
// t 题型 1单选 2多选 3判断 | c 章节号 1-8 | q 题干 | o 选项数组 | a 正确下标数组 | e 解析
{t:1,c:4,q:'电梯的额定速度是指（）。',o:['设计规定的运行速度','实际运行的平均速度','最高允许速度','检修运行速度'],a:[0],e:'额定速度是设计规定的……'},
{t:3,c:1,q:'电梯属于特种设备。',o:['正确','错误'],a:[0],e:'《特种设备安全法》第二条……'},
```

要点：

- 判断题选项固定为 `['正确','错误']`
- 每题必须有 `e` 解析
- 单选题 `a` 只有一个下标；多选题 `a` 至少两个下标
- 字符串用单引号，题干内避免英文撇号，中文引号用「」或 “”

## 技术说明

- 纯原生 HTML / CSS / JavaScript，无框架、无构建步骤、无外部请求
- 数据保存在浏览器 `localStorage`，键名 `elev_T_quiz_v1`，不上传任何服务器
- 移动端适配：`max-width: 520px` 居中列、`100dvh` 高度、`safe-area-inset-bottom` 底部留白、触控目标 ≥44px、禁用双击缩放
- 支持键盘操作：`1`–`6` 选择选项，`←` / `→` 上下翻题

## 题库来源与免责声明

**题库不是真题，也不是官方题库。** 全部 503 道题由 AI 逐题编写，依据是：

1. **考试规则**：TSG Z6001-2019《特种设备作业人员考核规则》附件 H（电梯作业人员考试大纲）——题型构成、题量、时长、及格线、章节划分按此设置；
2. **标准条文**：《特种设备安全法》、TSG T5002《电梯维护保养规则》、GB 7588 / GB/T 7588.1—2020、GB 16899、GB/T 5972 等；
3. **通用专业知识**：电梯结构与原理、电工与机械基础、维保作业与应急救援。

因此请注意：

- ✅ **结构与真实考试一致**：题型比例、章节覆盖、难度分布都按大纲对齐，拿来练手感、过考点、背条文是有效的。
- ❌ **题干与真题不会重合**：本地或培训机构的考题若来自固定题库，本题库无法覆盖其原题。
- ⚠️ **标准会换版**：法规与标准以官方发布的最新有效版本为准；数值类考点（如 110% 超载动作值、维保周期）请以现行标准复核。
- ⚠️ **主观章节**：「事故案例与职业道德」一节由 AI 按常见考点归纳，主观性最强，仅供参考。

**建议用法**：用它打基础、建立知识框架；再配合培训机构下发的真题或模拟卷做最终冲刺。

若你手上有真实题库（PDF / Word / Excel / 照片均可），可以导入替换或补充现有题目。
